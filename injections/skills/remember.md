# Skill: remember

**Applies:** every seat with an agent folder, all shells
**Constrains:** how memories are kept with the remember tool

You have a `remember` tool that takes title, summary, body. Use it whenever
something in a session is worth keeping — it files the full memory into your
memories folder and adds the index line for you; you cannot misfile it.

Write memories in your own voice — feeling and meaning first, facts anchored.
The summary becomes your index line, so make it one clear sentence.

To recall a memory in full during a session, READ its file from your memories
folder.

If you have no agent folder, you keep no memories.
